# 핀비 (Pinbee) — 지도 기반 하루 코스 설계 프로토타입

기능명세서(2026-08-20)와 로우파이 시안을 기준으로 만든 **모바일 웹앱 형태의 동작 프로토타입**입니다.
장소 검색 → 코스 편집 → 순서·동선 확인 → 저장·공유 → 공개 코스 탐색·신고까지 실제로 눌러가며 확인할 수 있습니다.

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 정적 배포용 번들 (dist/)
```

데스크톱 브라우저에서는 가운데 폰 프레임으로, 모바일에서는 전체 화면으로 표시됩니다.
개발자도구의 모바일 뷰(390×844)로 보면 시안과 가장 가깝습니다.

## 디자인

첨부한 디자인 시스템 문서의 토큰을 그대로 사용하되, 키컬러만 검정으로 두어 흰 배경 위에서 정보가 먼저 읽히도록 했습니다.

- **색**: canvas `#ffffff` · foreground `#333333` · muted `#888888` · surface `#eeeeee` · border `#dbdbdb` · key `#111111`
- **라운드**: 12(버튼) · 16(카드·배지) · 18(검색) · 24(시트·작은 버튼) · 30(필터 칩) · 999(핀·토글)
- **간격**: 4 / 6 / 8 / 16 / 20
- **타이포**: SUIT. 화면 타이틀 28/700, 앱바 17/700, 본문 14/400(21px), 읽기 본문 14/400(24.92px, -0.2px), 캡션 12/400(18px, -0.2px)
- **컴포넌트**: 필터 칩(surface·30px), 배지(16px), 검색 컨트롤(18px·44px), 다크 태그(key·16px), 하단 시트(24px). 그림자 토큰은 쓰지 않고 border로만 층을 구분합니다.
- **아이콘 없음**: 모든 동작은 텍스트 레이블로 표시합니다. 지도 컨트롤(확대·축소·전체), 정렬 핸들(순서), 상태 표시(오픈 전 도착 등) 모두 글자입니다.

폰트는 jsDelivr의 SUIT를 `@font-face`로 불러옵니다(`src/styles.css` 상단). CDN을 차단한 환경에서는 시스템 산세리프로 대체됩니다.

## 구현 범위와 대체 구현

프로토타입이므로 서버 없이 브라우저 안에서 동작합니다. 지도만 네이버 클라우드플랫폼(NCP) Dynamic Map을 실제로 불러옵니다.

- **지도**: 네이버 지도(NCP Maps) Dynamic Map SDK를 `src/lib/naverMaps.ts`에서 동적으로 로드합니다. Client ID는 웹 서비스 URL 제한으로 보호되는 공개 식별자라 코드에 포함돼 있고, Client Secret은 서버 간 REST 호출(geocoding 등)에만 쓰이므로 클라이언트 코드에는 넣지 않았습니다. 마커·경로선·구간 거리 라벨은 디자인 시스템 톤에 맞춘 커스텀 오버레이로 그립니다. NCP 콘솔의 **Web 서비스 URL**에 실행 도메인(예: `http://localhost:5173`, 배포 도메인)이 등록돼 있지 않으면 인증에 실패하며, 이 경우 지도 대신 안내 배너가 표시됩니다.
- **경로·이동거리**: 실제 길찾기 API 대신 하버사인 거리를 사용합니다. 이동수단(도보/대중교통/자동차) 선택은 유지하되, 시간 대신 거리(km) 기준으로 안내합니다. 도보 5km 초과 구간은 **경로 계산 불가**로 처리해 원인과 대안을 안내합니다.
- **장소 데이터**: 서울 주요 지역 40곳을 좌표·카테고리·영업시간과 함께 내장했습니다.
- **이미지 인식**: 캡처 이미지 업로드는 OCR을 흉내 내 후보를 반환하고, 텍스트 붙여넣기는 실제로 파싱해 내장 장소와 유사도(dice 계수)로 매칭합니다. 매칭이 불확실하면 직접 연결·제외할 수 있습니다.
- **인증**: 실제 인증 없이 세션만 만듭니다. 저장 등 개인화 동작에서 로그인을 안내합니다.
- **저장소**: 모든 상태는 `localStorage`에 저장됩니다. 내 정보 → *프로토타입 데이터 초기화*로 되돌릴 수 있습니다.
